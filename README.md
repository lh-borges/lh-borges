## 💻 O que eu faço

**☕ Desenvolvimento de software com Java**
- APIs REST, gRPC e GraphQL com Spring Boot, Spring MVC, Spring Data JPA e Spring Security
- Microsserviços com Spring Cloud, Clean Architecture, SOLID e Design Patterns
- Mensageria e arquitetura orientada a eventos com Kafka, RabbitMQ e MQTT; CQRS e Event Sourcing
- Testes com TDD, JUnit, testes de integração e E2E

**📊 Análise de dados com Python**
- Exploração, limpeza e transformação de dados com Pandas e NumPy
- Visualização com Matplotlib, Seaborn e Plotly
- Estatística, inferência e testes de hipótese
- Machine Learning com scikit-learn, do preparo dos dados à avaliação dos modelos
- SQL analítico e dados de séries temporais

**⚙️ Integração de sistemas**
- Dashboards web em Angular consumindo APIs em tempo real
- Integração de dados de campo (CLPs, SCADA e sensores) com backend e bancos de dados
